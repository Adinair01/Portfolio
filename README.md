# Portfolio – Latest Updates Overview

A modern, responsive portfolio built with **Next.js**, **TypeScript**, **Tailwind CSS**, and **shadcn/ui**.  
It showcases my **projects**, **skills**, **competitive programming profiles**, and **contact options** with smooth animations and a clean **dark theme**.

## Key Features

- Responsive UI optimized for **desktop + mobile** (sidebar + mobile drawer)
- **Projects**, **Skills**, and **Experience** sections with rich visuals and subtle motion
- Competitive programming links:
  - GitHub, LinkedIn
  - LeetCode: **https://leetcode.com/u/adiii01/**
